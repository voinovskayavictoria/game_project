# OSINT Detective — Galaxy S24 Emulator

React + Vite + Tailwind CSS эмулятор Samsung Galaxy S24 с интерактивным диалогом в стиле ARG/OSINT расследования.

## 🎯 Что это?

Интерактивный эмулятор смартфона, имитирующий экран блокировки, домашний экран и приложение "Сообщения" с полноценным диалогом:

- **Lock Screen** — часы, дата, погода, уведомления
- **Home Screen** — сетка приложений + док-бар в стиле Samsung One UI
- **Messenger** — чат с Машей (диалог с выбором, проверка кодового слова "Соколов", индикатор печатания)

## 🚀 Установка и запуск

### Требования
- Node.js 18+
- npm или yarn

### Установка

```bash
# Перейти в папку проекта
cd app-react

# Установить зависимости
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение откроется на `http://localhost:5173`

### Сборка для production

```bash
npm run build
```

Результат в папке `dist/`

## 📱 Логика диалога

1. **Старт** — Маша спрашивает "Кто это?"
2. **Выбор** — 3 варианта ответа:
   - ✅ "Я журналист" → ведёт к проверке кодового слова
   - ❌ "Мне нужна информация быстро" → блокировка
   - ❌ "Я ошибся номером" → блокировка

3. **Вторая проверка** — 3 способа доказать свою позицию (все ведут к вводу фамилии)

4. **Кодовое слово** — нужно ввести "Соколов" (прописными/строчными)
   - ✅ Правильно → полный лор + ссылка на teletype
   - ❌ Неправильно (3 попытки) → блокировка

5. **Финал** — 2 варианта финального ответа

## 🎯 Кастомизация

### Добавить новое приложение

В `HomeScreen.jsx` добавьте в массив `APPS`:

```javascript
{ 
  id: 'my-app', 
  icon: '🎮', 
  name: 'Мое приложение', 
  color: '#5e5ce6' 
}
```

### Изменить диалог

Отредактируйте функции `answer*` в `Messenger.jsx` и функцию `addBotSays`.

### Изменить цвета

Обновите переменные в `index.css`:

```css
:root {
  --blue: #1a86ff;        /* Меняйте на свой цвет */
  --green: #30d158;
  /* ... */
}
```
